# Cross-lab documentation

This directory is for longer-form material that applies across labs:
explanations, comparisons, conventions and their reasoning, and shared
background.

Lab-specific teaching belongs in each lab's README. Operational rules for
changing a lab belong in [AGENTS.md](../AGENTS.md).
